Intelligent Vehicle Monitoring System (IVMS)

Project Overview

The Intelligent Vehicle Monitoring System (IVMS) is a computer vision-based application developed to automate vehicle monitoring using CCTV footage. The system detects vehicles, recognizes vehicle number plates, records entry and exit times, and maintains digital vehicle records.

The project integrates **YOLO, OpenCV, EasyOCR, Flask, and SQLite** to provide an automated and user-friendly vehicle tracking solution.

Key Features

-  Automatic vehicle detection using YOLO
-  Vehicle number plate recognition using EasyOCR
-  Automatic entry and exit time recording
-  SQLite database for vehicle records
-  Flask-based web dashboard
-  Vehicle monitoring and statistics
-  Excel report generation
-  CCTV/video-based vehicle tracking
